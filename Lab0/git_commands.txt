git clone - Клонирование репозитория
git status - просмотр состояния репозитория
git add <файл> - добавить в проект что-то какие то изменения файлов
git add - добавить сразу все файлы которые изменены
git commit -m "text" - сохранить изменения с комментарием
git push - отправить свои коммиты на репозиторий
git pull - вернуть изменения/откатить с репозитория
git log - история коммитов
git branch - список веток
git init - Создать новый репозиторий в текущей папке
